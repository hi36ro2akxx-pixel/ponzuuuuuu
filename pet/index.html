制作ツール / スキル Figma / HTML / CSS
ターゲット 愛犬との暮らしを大切にし、お部屋のインテリアにもこだわりを持つ20〜40代の飼い主層。
制作目的 ペット用家具・インテリアの魅力を直感的に伝え、温かい世界観への共感とブランドのファン獲得（お問い合わせ促進）を図る。
コンセプト 「みんないっしょに、心地いい空間へ。」愛犬と暮らす、洗練された心地よさとぬくもりのある空間の提案。

温もりと洗練を両立する、
ナチュラルなデザイン

ブランドの象徴である愛犬のビジュアルと、自然の光や木の質感を思わせるグリーンを基調に配色しました。すっきりと整理されたレイアウトと大きなメインビジュアルにより、訪れた飼い主の心に「心地よさ」と「安心感」を直感的に感じさせるデザインに仕上げています。[cite: 1]

「インテリア・家具」をはじめとする
スムーズな情報設計

こだわりのペット用家具や、日々の暮らしを豊かにする特集・読み物という主要なコンテンツが、ユーザーに一目で伝わるようカード形式で分かりやすく整理しています。どのデバイスから閲覧しても迷うことなく、スムーズに必要な情報やお問い合わせへアクセスできるようなユーザビリティを意識して構築しました。[cite: 1]
